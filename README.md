# Cynbit Technologies - AI Discovery Assistant & Lead Capture

### Overview
A practical full-stack technical assessment prototype designed to enhance Cynbit's website conversion funnel by transforming static visitor traffic into qualified enterprise leads.

### Identified Problem
Enterprise buyers evaluating high-complexity services (AI automation, platform engineering) often face high friction with standard static forms, resulting in drop-offs before project initiation.

### Solution & Key Capabilities
- **Real-Time Discovery Widget:** Interactive assistant that helps prospective clients identify the right engineering solutions.
- **Intent Classification Engine:** Routes visitor queries between AI systems, platform scalability, and project estimations.
- **Integrated Lead Capture:** Directly records qualified client leads with timestamp and interest tracking.
- **Relational Data Persistence:** Clean schema in MySQL via Spring Data JPA.

### Tech Stack
- **Backend:** Java 17, Spring Boot 3.2.5 (Spring Web, Spring Data JPA, Hibernate)
- **Database:** MySQL 8.0
- **Frontend:** Thymeleaf, Vanilla CSS3 (Custom Dark-Tech Theme), Modern Vanilla JavaScript (Fetch API)
